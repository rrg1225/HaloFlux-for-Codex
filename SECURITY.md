# Security policy

HaloFlux for Codex is an unofficial local bridge for a single user. The browser and desktop packages use an installed Codex CLI, loopback HTTP and explicit approvals. The desktop build gives the overlay a read-only status channel and restricts the operation credential to POST requests from the trusted control document. [Local security model](docs/SECURITY.md) · [Electron audit](docs/DESKTOP-SECURITY.md)

Report suspected vulnerabilities privately to the maintainer using a private contact channel. Include the HaloFlux and CLI versions, steps using simulated data, expected and actual behavior, and a redacted diagnostics report. Keep credentials, approval tickets, session data and exploitable details out of public issues. The repository has no remote reporting endpoint configured in this local release.
