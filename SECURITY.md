# Security policy

HaloFlux for Codex is an unofficial companion for a single local user. The browser and desktop editions use an installed Codex CLI, loopback HTTP and explicit approvals. The desktop build gives the overlay a read-only status channel and restricts the operation credential to authorized requests from the trusted main window. [Local security model](docs/SECURITY.md) · [Electron audit](docs/DESKTOP-SECURITY.md)

Use an existing private contact channel with the maintainer to report suspected vulnerabilities. Include the HaloFlux and CLI versions, the expected and observed behavior, and steps using simulated data. Attach a redacted diagnostics report if it helps reproduce the issue. Use GitHub Issues for general bugs and keep credentials, approval tickets, session data and vulnerability details out of public reports.
