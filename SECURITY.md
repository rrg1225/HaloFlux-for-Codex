# Security policy

HaloFlux for Codex is an unofficial local bridge for a single user. The current release candidate uses an installed Codex CLI, loopback HTTP and explicit approvals. Review the trust boundary, approval rules and validation record before deployment. [Local security model and audit](docs/SECURITY.md)

Report suspected vulnerabilities privately to the maintainer using a private contact channel. Include the HaloFlux and CLI versions, steps using simulated data, expected and actual behavior, and a redacted diagnostics report. Keep credentials, approval tickets, session data and exploitable details out of public issues. The repository has no remote reporting endpoint configured in this local release.
