## 统计口径

| 指标 | 取样点 |
| --- | --- |
| rAF 间隔 | 用 `performance.now()` 记录每次进入实际回调的时刻，并另存 rAF 提供的时间戳。 |
| 绘制 FPS、绘制间隔 | 进入 `drawStage` 的次数除以实际窗口秒数。由相邻进入时间计算 P50、P95、P99。 |
| JS 状态更新 | 在独立详细样本中累计 `updateBeat`、`updateCam`、`updateOuter`、`updateRing` 的同步用时。 |
| 绘制函数 | 记录 `drawStage` 进入和返回之间的同步时间，包含状态更新与可能的同步等待。 |
| 提交与呈现反馈 | 独立 CDP trace 通过 Chromium 同一帧的提交与呈现反馈事件计时。物理显示扫描与 GPU 硬件计数器没有测量。 |
| Long Task 与 GC | `PerformanceObserver` 记录当前窗口的长任务。独立 trace 分别统计渲染器主线程 MinorGC 和 MajorGC。 |
| 工具与节流 | 轻量、详细和 trace 样本分开统计。记录页面可见性和测试定时器超期。 |

## 已定位的停顿

v0.3.0 的设置处理把 `autoQuality` 变化直接当成画布重建条件。五个独立的 1080p / DPR 1 窗口各切换四次，后备尺寸全程 1270 × 635，每个窗口仍有四次 `resizeStage`，帧间隔 P99 出现约 100 ms 及以上的停顿。候选版把重建限制在有效 DPR 或构图参数变化。画质档、五层光束、辉光、粒子及颜色合成仍走原绘制路径。性能面板采样改用实际进入绘制前的时刻。相同设置的稳态样本另行比较。

## 历史回归与稳态瓶颈

v0.3.0 的历史报告在 1080p 固定 60 档记录 19.02 → 17.95 FPS，绘制间隔 P95 391.87 → 250.23 ms，绘制调用 P95 均约 8.43 ms。本轮首次冻结基线复测，v0.2 / v0.3 五次均值为 34.21 / 36.37 FPS，历史长尾量级也没有重现。旧报告只有三个约 2.5 秒窗口，测量脚本用 rAF 时间戳标记绘制，当前基准用实际回调时钟与独立上下文。历史平均 FPS 差值的具体原因仍未确定。

同条件下跳过重复绘制时，rAF P95 由动态场景约 36–40 ms 降到 4.4–4.5 ms。两份动态无头基线的 trace 记录了 `Swap throttled`（383 / 379 次），提交至 Chromium 呈现反馈 P95 为 81.57 / 77.07 ms，交换完成至反馈约 3.91 / 3.95 ms。GPU 进程光栅调用 P95 为 17.12 / 16.41 ms。数字来自含热身的独立 trace，覆盖不同的管线事件，不能逐项相加。结果显示 JS 返回后仍有光栅与等待交换的成本。 [Chromium DisplayScheduler 源码](https://chromium.googlesource.com/chromium/src/+/main/components/viz/service/display/display_scheduler.cc)

## 复测命令

将两份基线分别解压至独立目录。使用已安装的 Playwright，保持同一 Edge 版本、显示模式与电源条件。

```powershell
$env:HALOFLUX_PLAYWRIGHT = 'C:/path/to/playwright/index.mjs'
$env:HALOFLUX_PERF_CASES = 'quality-toggle,fixed,auto,static,original'
$env:HALOFLUX_PERF_MODES = 'headless,headed'
$env:HALOFLUX_PERF_SCREENSHOTS = '1'
node scripts/edge-matrix.mjs 'C:/scratch/haloflux-v02' 'C:/scratch/haloflux-v03' .
```

诊断对照用 `HALOFLUX_PERF_CASES=fixed,static,detail,native-raf,no-css,no-filters,no-timers`。指定 `HALOFLUX_PERF_OUTPUT` 可分别保存结果。设置 `HALOFLUX_PERF_TRACE=1`，对固定档的第 5 个样本额外采集独立 trace。用 `node scripts/edge-trace-summary.mjs <trace.json.gz>` 复算统计。JSON 保留原始时间戳、窗长、分位数与六个分桶（≤8.33、≤17、≤33.33、≤50、≤100、>100 ms）。
