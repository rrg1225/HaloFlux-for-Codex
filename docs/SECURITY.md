# 本地安全模型

HaloFlux 在 `127.0.0.1` 监听。动作与私有读取通过同一个 JSON POST 入口，校验精确的 Host 和 Origin、同源 Fetch Metadata（浏览器提供时）、媒体类型和每次桥接启动随机生成的操作令牌。令牌由控制台页面获取，保存在页面内存。页面和 API 响应禁止缓存。控制台禁止被嵌入，脚本 CSP 仅允许同源外部脚本。托管原版 Canvas 额外允许其内联脚本的 SHA-256 哈希。原版文件本身保留原字节。

公开 SSE 仅包含来源各自的状态、固定活动类别、计数、结果和版本号。请求 ID、预览票据、路径、命令、对话、输出和错误原文不经过 SSE。审批正文在用户展开请求时读取，对话在用户打开任务详情时读取。断开 SSE 时页面清空私有视图。HaloFlux 不把审批、会话或令牌写入应用日志和本地存储。Codex CLI 按自身配置管理模型请求和本地会话历史。

浏览器动态正文用 `textContent`、`Option` 和表单控件渲染。补丁和命令是只读文本。未经过可信审查的 MCP URL 不会生成链接或发起访问。支持的拒绝动作由协议提供。对未知协议请求返回 JSON-RPC 错误。

## 审批生命周期

- 实时任务以只读、关闭沙箱网络和人工审查为默认设置。CLI 的审批策略与管理策略仍然生效。预授权的只读操作可能正常运行。
- 本地单次许可绑定 App Server 连接、请求 ID（保留数字或字符串类型）、线程、轮次和当前预览票据。补丁发生变化时，旧预览票据失效。缺少完整命令、工作目录或文件补丁时，批准不可用。
- 仅发送 Schema 和当前请求允许的一次性决定。无会话级批准或持久策略改写。申请 `grantRoot` 的文件请求仅提供拒绝。网络审批显示目的地和协议。额外权限仅授予 Codex 实际请求且展示给用户的范围，作用域为当前轮次。普通用户输入按问题提交，敏感输入和 MCP 表单、URL 请求采用拒绝。
- 请求最长有效 120 秒。Codex 的更短输入期限优先。超时只会拒绝。中断开始后锁定审批，轮次终态、服务器撤销、进程断开或成功提交决定都结束相关本地票据。刷新后的默认视图折叠私有内容，仍有效的请求可重新打开审查。
- 本机生成的 Schema 须支持只读、关闭沙箱网络和人工审查参数，否则实时连接失败。缺少具体审批响应格式时，相应操作关闭。未关联轮次的 MCP 请求直接拒绝，URL 不会打开。
- 「已提交批准／拒绝」记录的是桥接写入决定的动作。执行结果由 Codex 发出的项目终态和轮次终态确认。

同一桥接的多个标签页可以主动查看同一个待审请求。决定先在桥接消费票据，再写入 App Server。迟到、重复或线程和轮次不匹配的提交会被拒绝。双标签回归用模拟请求验证两个浏览器提交只消费一次，并验证上一轮票据无法处理新一轮。真实线格式和线程作用域另外由离线 JSONL 夹具覆盖。

## 健康检查与导出

健康检查使用现有同源、令牌鉴权的 POST 入口。CLI 探针只运行版本和登录状态检查。Windows 沙箱已有错误标记只在内存提取固定类别。报告包含允许列表内的版本、状态、失败类别、浏览器 DPR 和可见性。私有路径、身份、对话、源代码、命令输出、令牌和运行日志原文不会写入诊断报告。

诊断脚本单独运行固定的只读回显命令，在原生 CLI 和独立 stdio App Server 上进行对照。沙箱由 Codex 按现有设置初始化。脚本只从新追加的日志内容提取已知错误标记，并输出二进制版本、摘要与执行状态。

隔离候选 CLI 时，初次实验使用空的临时 `CODEX_HOME`，不复制用户认证或配置。先验证发行摘要和可执行文件签名，再按明确授权执行无模型握手。沙箱探针可能触发 Windows runtime 初始化或 ACL 写入，需在批准的范围内执行。 [实验边界](SANDBOX.md)

信任边界是当前 Windows 用户和其浏览器。能读取回环页面的本机程序、恶意浏览器扩展和被控制的本机环境不在网页令牌的保护范围内。此实现面向单机使用。
