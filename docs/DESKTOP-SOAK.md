# v0.4.0-beta.1 桌面长时间稳定性

用固定的 Electron 45.2.3 Windows x64 在临时用户配置中运行至少 1800 秒。测试启动一个受控 Mock App Server 轮次。每轮切换主窗尺寸及两窗自动质量，播放模拟任务，测量双窗持续绘制，再最小化主窗、关闭悬浮窗、进入托盘并恢复。

每个样本记录两个 renderer 的绘制间隔、画布与中间缓冲区尺寸、进程 CPU、Windows working set、Private Bytes 和可获得的 JS heap。每轮确认桥接 PID 一致、Mock 轮次仍活动，且只有主窗的一条 SSE。每八轮延长托盘驻留，检查主窗 Canvas backing store 归零。专用显存为 **UNKNOWN**。

## 首轮与高 DPI 回归

按场景分开运行短时性能矩阵。此耐久测试包含无头浏览器回归与打包预检等并行本机活动，样本用于驻留、资源和状态连续性分析。分进程口径与数值见[进程报告](DESKTOP-PROCESSES.md)。
