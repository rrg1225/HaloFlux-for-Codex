# 有头 Edge 双标签超时排查

## 复现和已定位问题

v0.3.1 的两次有头严格长测在刷新后等待模拟审批时超时，已有记录仅定位到等待步骤。用 Stage 0 冻结源码、原脚本和 `pw:api` 重跑一次，129.4 秒内完成 12 次刷新、24 次切换和关掉第二页后的新绘制。两页在该次运行报告 `visible`。本轮这次重跑未重现历史超时，历史失败的具体原因仍未确认。

本轮复验独立定位了两个测试框架问题。

- 有头单页在 1366 宽度触发旧横向溢出断言。旧脚本将 `scrollWidth` 与包含竖向滚动条的 `innerWidth` 比较，原生滚动条可使差值为负。改用根元素 `clientWidth`，仍要求横向溢出为零，并在失败时记录尺寸和样式。
- 首次双标签分段复验在第 1 次刷新时失败。约 3.525 秒时第二页的新 EventSource 收到 HTTP 200 和 revision 4 的待审快照，错误快照显示审批可见、连接就绪，画布继续绘制。CDP 没有为导航前的旧连接发出终止事件，测试仍把旧请求计入当前文档。修正为在顶层导航时清空旧文档的 CDP 记录，并用桥接进程内的实际响应计数独立验证连接清理。该现象来自本轮新观测器。

模拟审批由演练定时器发出，在收到决定或演练中断前保持有效。实时请求的 120 秒期限独立由 `CodexSession` 管理。原测试使用模拟请求，不能用实时请求的过期机制解释历史超时。源码和本轮复验未给出产品死锁、两个标签分别消耗一次同一票据或永久 SSE 失联的证据。

## 分段验证

| 段 | 独立等待和断言 |
| --- | --- |
| A 单标签 | 完整布局、设置、模拟审批、失败终态和健康导出见冒烟。双标签脚本从单页刷新开始，要求桥接上仅一条流且首个快照能恢复 DOM。 |
| B 双页打开 | 两页建立连接，打开第二页时保持模式，桥接计数为二。 |
| C 持续 SSE 与真实断线 | 同一 revision 和审批数到达两页。服务端结束两个响应，校验离线状态和私有卡清空。重新连接后恢复同一待审请求，私有卡保持折叠。 |
| D 模式切换 | 24 次真实按钮点击，检查模式、桥接可用和原模拟审批恢复。 |
| E 刷新与重连 | 12 次真实导航，逐轮检查新 HTTP 200、快照、DOM 待审批及桥接响应数。每轮保留原 10 秒压力停留。 |
| F 审批竞争 | 两页独立打开并获取同一演练票据，同时提交一次拒绝。校验一条 HTTP 200、一条 HTTP 400、一个拒绝时间线记录和两页终态，旧票据不能处理下一轮。实际线程、轮次和请求作用域由离线 JSONL 回归覆盖。 |
| G 可见性与绘制 | 测量自然后台可见性。若浏览器仍报告两页可见，单独用受控 `visibilitychange` 测试后台取消绘制路径。要求前台收到新样本、恢复后第二页重新采样、关闭第二页后第一张画布继续采样。 |

非绘制状态用主机时钟轮询，超时会记录具体在途步骤。交互、导航和非绘制状态默认 10 秒，前台新绘制窗口沿用 20 秒。每轮保留页面可见性、焦点、SSE 连接、快照 revision、Canvas 样本、JS 堆和浏览器主线程累计任务时间。主进程记录 Edge 子进程资源，关闭后核对所观测 PID。报告只记录模拟会话和聚合字段。

## 实测结果

**MOCK VERIFIED**。有头 Edge 156.0.4314.58，1366 × 768，设备缩放设为 1。单页完整冒烟通过。连续五次双标签核心压力测试分别为 138.343、138.727、138.807、138.651、138.529 秒。合计 60 次刷新、120 次模式切换和五次两页同时断线恢复。每轮两个提交分别返回 200 和 400，任务时间线只有一次拒绝。五轮均收到关掉第二页后的新 Canvas 样本，页面异常和观察到的 Edge 残留进程均为零。前台页回收后 JS 堆采样约 3.31–4.16 MiB。

默认 Playwright 长测中的两页报告可见，G 段使用受控可见性事件。另一次尝试用该启动方式最小化窗口，未观察到原生 `hidden`，保留失败证据。独立脚本改用临时 Edge profile 和 CDP `noDefaults`，保留浏览器原生可见性。隐藏页实际报告 `hidden`，收到模拟审批的 SSE 并更新 DOM，测试 rAF 未执行且无新 Canvas 样本。切回后同页报告 `visible`，先前挂起的 rAF 和新 Canvas 样本均恢复。由此复现了隐藏时绘制等待与 DOM 状态推进的差异，历史超时仍缺少对应的现场数据。 [CDP 焦点模拟接口](https://chromedevtools.github.io/devtools-protocol/tot/Emulation/#method-setFocusEmulationEnabled)
