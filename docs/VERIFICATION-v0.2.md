复测时用 `npm.cmd start` 启动模拟桥接。在项目目录先创建 `output/playwright`，然后运行以下命令。需要 npm 提供的 npx 以及已安装的 Edge。

```powershell
npx.cmd --yes --package @playwright/cli playwright-cli -s=haloflux-test open http://127.0.0.1:4637 --browser msedge
npx.cmd --yes --package @playwright/cli playwright-cli -s=haloflux-test run-code --filename scripts/edge-smoke.js
```

在另一终端运行 `node scripts/edge-bridge.mjs` 后，用不同 Playwright 会话打开 `http://127.0.0.1:4647`，运行 `scripts/edge-live.js`。测试桥接在拒绝后的轮次终态核对目标文件不存在，然后主动结束 SSE，测试浏览器恢复原线程和结果。

## 发布完整性

11 个原始文件的 SHA-256 与修改前工作区及上游提交 `016bef651c4f911f08039ba159d36a6f246ff5d2` 全部一致。检查包含 LICENSE、桌面和移动端入口、预览、音轨和壁纸文件。 [原始文件哈希](ORIGINALS.sha256) · [上游提交](https://github.com/Ryder191/haloflux/tree/016bef651c4f911f08039ba159d36a6f246ff5d2)

ZIP 解压到带空格的 Windows 路径后，`Start-HaloFlux.cmd` 检测到 CLI 和登录，默认 Edge 连入服务，解压副本成功连接 App Server。解压副本的离线测试及协议检查也通过。重复占用端口时启动退出并打印诊断。按 Ctrl+C 后，监听端口和已连接的 Codex 子进程均退出。将测试进程的 `CODEX_BIN` 指向不存在的文件时，启动器正确显示 CLI 不可用。

发布脚本以文件白名单打包。对发布内容扫描常见密钥、私钥和本机用户目录模式，未发现匹配。

## 开放项

- **FAIL（本机环境）**。Windows 沙箱辅助程序初始化失败，未经人工批准的只读命令在本机返回失败。真实人工批准通道已独立验证。
- **性能上限**。本机本轮测试低于 60 FPS。
- **NOT TESTED**。实体平板、其他 Windows 设备、Node.js 22 的安装矩阵，以及物理浏览器标签页切换造成的系统级后台调度。
- **NOT TESTED（真实服务）**。网络、额外权限、普通用户输入及 MCP 拒绝通过协议检查和离线线格式测试，未在真实模型轮次中触发这些类别。
